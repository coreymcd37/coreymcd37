## How I work

I build with an AI-assisted workflow that I direct. I set the goal and the constraints, review every change, test the result in real browsers and decide what ships. AI speeds up the work, but the judgment stays with me.

- **Security first** – audit before building, keep secrets out of the client, and treat every input as untrusted
- **Cost-aware** – the right tool and the right amount of context for each task
- **Measured** – accessibility, performance and SEO checks before launch, not after
- **Honest content** – no placeholder claims; only details that can be verified go live
